№ 02 · The Premise
More than a coding agent

Not just an
autocomplete.
An entire

Codex is OpenAI's software engineering agent. It writes code, sure — but it also runs commands, runs tests, explores codebases, and can do essentially everything a software engineer would do. Underneath sits a unified agent harness: a wrapper for tool execution, environment setup, evaluation, and safety. The model is the engine; the harness is the car.

You meet it through whichever surface you prefer.

№ 05 · The Bundle
Plug-ins Skills × Apps × MCP
One install, one workflow

Stop wiring it
up every time.

Plug-ins bundle skills, apps and MCP servers into reusable workflows you install once. Bring your own — or grab a featured one and go.

What's inside the bundle
  • Skills — reusable instructions, scripts and resources for processes you do over and over.
  • Apps — connections to services you already use: Notion, Linear, Figma, Slack, Gmail, Google Drive.
  • MCP servers — external tools that extend Codex's capabilities at the protocol level.
The two showstoppers
  • Playwright Interactive — Codex spins up a sandboxed browser, clicks around your app, takes screenshots, and reasons about what it sees.
  • Image Gen — Native asset generation. Hand it “a platformer with brick platforms” and it ships sprites, backgrounds, characters — then drops them into the game.

Result of one prompt: a fully playable platformer with five animated sprites for the character. Zero hand-edits.

№ 07 · Quality Control
An opinionated reviewer

The first pass
is no longer yours.

A

As the volume of agent-written code climbs, no human can read every line. So the first review needs to come from somewhere else — and Codex code review has, in VB’s “biased” admission, become “one of the best in the industry right now.”

Spin it up via /review in the CLI or app, hook it into GitHub for automatic PR comments, or call it from inside another agent harness via the freshly shipped Claude Code plug-in.

What makes it good isn’t the diff itself. It’s the contextualising: Codex spins up a fresh process, applies its own review system prompt, and looks past the changed lines into the rest of the repo — surfacing second-order effects in modules the PR never touched.

From the talk

“100% of pull requests across all OpenAI repos — made by all employees, including Greg — are reviewed by Codex code review by default.”

P0

Must-fix. Bug, regression, or security issue Codex believes will break things.

P1

Should-fix before merge. Often: localise this string, translate that label, narrow this type.

P2

Good-to-have. The polish layer. Take it or defer it — with eyes open.

№ 09 · Parallel Lives
The Sub‑Agent Broadsheet
Workshop Edition · Sec. C

Spin up twenty.
Let them tear
through the repo.

“Sky is literally the limit. You can spin up as many agents as you want.” Decompose the master task; hand each slice to its own Codex process; collate at the end.

Live demo · 45 personas reviewed by 20 spawned sub-agents, partitioned and collated by the parent Codex thread.
The Pattern

Decompose, dispatch, collate.

The parent Codex thread classifies the task as complex enough to deserve plan mode — on its own, no prompt — partitions the work, and spawns children. Each child gets a tailored persona, a file slice, and the relevant repo guidance (READMEs, contributing docs, skill files).

A Found Limit

Six concurrent threads — for now.

Live on stage, VB hits a cap of six concurrent agent threads on his machine. The other fourteen queue up. The point isn’t the ceiling; the point is that it lifts. The same pattern works for security scans, brainstorming five different feature implementations, or running adversarial reviews from different hypotheses.

The Quiet Trick

Mini & nano change the cost shape.

Sub-agents pair beautifully with GPT 5.4 mini and nano. Each child is short-running and cheap; the parent stays on the heavyweight model. You parallelise the work without paying twenty parallel premium-model bills. That’s the unlock.

№ 11 · The Bleeding Edge
Experimental drawer

Hooks. Guardians.
Personalities.
Unlock them.

A handful of features have shipped without much of a splash. Toggle them on with /experimental and the harness changes shape under you.

G
Guardian Approvals

Spawns a verifier sub-agent on every privileged action. Most pass automatically. Ends the YOLO-mode fatigue without giving up oversight.

H
Hooks — three of them

Session start · after each tool use · session stop. Programmatic Codex actions on every event. Stop-hook + “keep going” script = a long-running task that won’t quit.

P
Personalities & Custom Instructions

Set Codex to friendly, pragmatic, or whatever fits the work. Layer in custom rules — e.g. “always cite what you do.”

S
Codex Security

State-of-the-art vulnerability finder for GitHub repos. Walks commit by commit, drafts a patch, hands it to Codex to apply.

C
Claude Code Plug-in

Shipped last week. Invoke Codex from inside a Claude Code session for the same review, an adversarial pass, or a rescue of in-flight changes.

// hooks.json

Three triggers, infinite scripts.

session-startpull latest from origin
tool-uselog to research notebook
session-stoprun keep_going_ui.py

The stop-hook is the cheat code. VB’s long-running tasks finish a turn, the hook fires, the script tells Codex to do one more pass. Loop forever — or until the work is genuinely done.
